04 / THE ENGINEERING

Every decision has a trail.

The work is in the connections: collecting the data, finding its shortcuts, shipping the model, and learning from its mistakes.

DATA + EVALUATION

Fix the shortcut.

Real browsing exposed a bias toward bare domains. Benign URL augmentation and consistent normalization address it. The committed regression check records zero trailing-slash verdict flips.

Explore the data pipeline
API + PRODUCT

Ship the decision.

One shared detection engine powers a FastAPI endpoint, an analyst dashboard, and a Manifest V3 Chrome extension. Explanations travel with the verdict.

Explore the API
ML LIFECYCLE

Close the loop.

SQLite corrections take effect immediately and enter the next training run. Scheduled updates ingest threats; a validation gate rejects accuracy drops over one percentage point.
